# 组合训练使用说明

更新：2026-11-02。已加入醒目的持仓股数与下单区撤单 / 撤单并修改入口；本地练习，无实盘功能。

## 打开页面

在项目根目录启动：

```powershell
.\.venv\Scripts\python.exe run_dev.py --portfolio-demo --data-dir .runtime/portfolio-quotes --users-dir .runtime/portfolio-users
```

打开 <http://127.0.0.1:5050>，创建或选择本地用户。右上角“新建训练”中可选择组合训练；“继续组合训练 / 报告”直接进入组合训练记录页。也可直接打开 <http://127.0.0.1:5050/portfolio.html>，使用顶部用户选择器。首次没有用户时，先返回首页创建用户。

PowerShell 启动器也支持 `./start_dev.ps1 -PortfolioDemo -DataDir .runtime/portfolio-quotes -UsersDir .runtime/portfolio-users`。桌面启动可在 Python 命令末尾增加 `--desktop`；新 Windows 安装包留在阶段六。

页面默认选择腾讯日线，与单股训练共用数据源。可自由选择 1–20 只 A 股及日期，开始时自动加载日线，非交易日起止会对齐区间内交易日。自由组合采用固定模拟费率，不计分红送转。旧新浪核验数据入口仍保留，范围和接入方法见 [REAL_DATA_VERIFICATION.md](REAL_DATA_VERIFICATION.md)。

`--portfolio-demo` 额外开放明确标注的合成数据源。演示三个代码仅作标识，价格、停牌和上市退市状态均为人工样本。自由组合与旧新浪核验数据采用不同的准入和核算规则，页面会说明具体口径；恢复已保存的行情与账户不需要重新下载数据。

## 新建与继续

1. 选择指定股票或随机盲盒、数据源、初始资金和日期范围。
2. 指定模式下搜索股票名称或六位代码，依次加入股票池；再次点击已选标签可移除，最多 20 只。盲盒模式下设置数量和训练时长。
3. 指定模式可点击“预览可用行情（可选）”查看范围，也可直接开始。
4. 点击“开始组合训练”，系统加载行情。所有股票共用一份现金和一个公共日期。
5. 右侧“我的组合训练”分为“待继续”和“已完成的训练”。点击“继续训练”恢复进度；点击“查看总结”回看已结束的训练。此入口与新建表单分开。

搜索结果的数据范围不代表区间内每一天都能成交。缺失行情、停牌等情况会在执行订单时按对应规则处理；旧新浪核验数据的额外准入格式见 [PORTFOLIO_API.md](PORTFOLIO_API.md)。

## 看图与下单

- 顶部大号日期是组合的公共日期，屏幕表示“截至该日收盘”。左侧列出股票收盘价、当天相对前一个有效收盘的涨跌、持有数量和数据状态；第一天没有前收盘时显示“—”。每张股票卡片用大号数字标出持仓股数，交易区另列当前股票的持仓总股数、当前可卖及委托冻结股数；底部持仓表将持仓与冻结分列显示。
- 点击左侧股票只切换日 K 和成交量，日期、现金、持仓和订单不变。训练中图表仅取截至公共日期的未复权日线。
- 右侧仿照原版使用红色“买入”和绿色“卖出”切换。数量默认单位为**手（1 手 = 100 股）**：输入 1 就是 100 股，输入 2 就是 200 股；可用加减和 1/5/10 手快捷按钮。卖出提供“卖出全部可申报持仓”，零股可勾选按股处理，仍由后端校验整笔零股规则。
- 右侧先从后端试算，显示预计执行日期、估算费用明细和冻结预算 / 股数。试算不落账；买入默认预留价格缓冲。正式下单后资金和可卖股数占用立即反映在所有股票的共享账户中。
- “当前可卖”不含当天买入以及已冻结的股票；“下一开盘可申报卖出”考虑下一交易日的 T+1。当天买入后可以提前提交下一日的卖单，但不能当天成交卖出。
- 点击“下一交易日”，公共日历、订单、所有股票和整个账户一起推进。订单按提交顺序使用下一日开盘价重新检查；资金不足不会产生负现金。
- 下单区下方直接列出全部待成交委托（包括其他股票），同股票、同买卖方向、同执行日期合并展示总股数和笔数；多笔委托默认折叠，展开后可逐笔“撤单”或“撤单并修改”。分组仅影响展示，各订单仍独立执行、计费和保留记录。后者先撤销原单并释放冻结额度，再把原股票、买卖方向及数量填回表单；调整后必须重新点击“提交委托”，新单会重新校验并保留独立记录。撤单失败或结果未确认时，不会进入修改步骤，应先处理提示或重试原操作。已成交订单不能撤销或修改。
- 底部切换“全部持仓 / 订单与撤单 / 成交记录 / 资产曲线”，订单表同样提供撤单及撤单并修改入口。实际成交费用以成交记录为准，可能不同于估算。

本页采用日线模拟：收盘后决策，推进前允许撤销待成交委托，下一交易日开盘尝试成交。这是训练中的简化时序，不模拟券商夜市委托、交易所盘中撤单时段或部分成交。实盘调整委托通常需要撤销未成交部分后重新申报；竞价交易在 9:20–9:25、14:57–15:00 等时段不接受撤单，详见[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)。

### 悬停详情、均线和多股对比

将鼠标移到 K 线或成交量上，上方行情条显示光标所指日期的开盘、最高、最低、收盘、成交量、涨跌幅和均线值；离开后恢复最新有效日线。K 线与成交量十字光标联动。

默认显示 MA5、MA10、MA20，可勾选 MA30、MA60。只按截至当前日期的有效交易日收盘计算，历史不足 N 日时明确显示“不足 N 日”，不会用未来行情补足。

主图上方切换“单股 K 线 / 多股对比”，共用原图表区域；不会改变公共日期或交易对象。“多股对比”显示所有股票的价格涨跌幅与组合账户收益率，可通过图例隐藏 / 显示曲线。个股以训练内首个有效收盘为 0%，账户以初始资金为 0%；停牌沿用最近价格，上市前留空。该图始终截至公共日期；报告中的完整区间选项仅影响单股复盘图。左下角 TV 是 TradingView 图表库来源标识。

下单区先选择买入或卖出，填写手数，在预览中核对执行日期、方向、股数和冻结金额，最后点击蓝色“提交委托”。方向切换只更新预览，提交后才创建订单。模拟口径、T+1、预算和图表脚注统一放在页面最底部小字“交易规则与数据说明”中，默认折叠；订单无效的具体原因仍在预览中即时显示。

### 自动播放

右侧“训练控制”提供自动播放 / 暂停和 0.5、1、2、5 秒 / 日速度。每次推进和保存完成后才等待下一轮，不会因慢请求重叠推进。它只自动推进日期并处理已有订单，不会自行选股或下新订单。

下单 / 调整数量、结束或返回列表会暂停播放；页面隐藏、订单被拒、请求冲突 / 中断也会暂停。到达区间末日后自动结束并展示总结。暂停时已经发出的本次推进可能仍会完成，之后不会再发起下一日。

想看足够长的均线，选择**“合成练习 · 多月均线与自动播放”**（需 `--portfolio-demo`），默认覆盖 2024-01-02 至 2024-06-28。价格和日历全部是人工样本，和真实历史数据分开。原 7 日演示样本仍保留，但不足以显示 MA10/20。

停牌、无有效成交、缺失行情、T+1 或成交拒绝均显示中文原因。停牌时可以使用带历史日期标记的价格估值，但不会使用该价格成交。日线无法重建盘口或排队，一字涨停买入、一字跌停卖出等按保守规则拒绝。

## 自动保存、重试与报告

页面顶部的“重置训练”会先暂停自动播放并弹出确认框，显示起始日期和初始资金。确认后本局回到起点，持仓、委托、成交、资产曲线和总结清空，保留原股票、日期区间及固定行情（盲盒也保留本局抽中的股票和日期，不重新抽取），无需重新下载。进行中或已结束的训练均可重置，原进度无法撤回；选择“保留当前进度”或按 Esc 则不重置。重置后仍是同一条训练记录，刷新或重启后可继续。

每次成功操作自动保存到指定用户根目录的独立 `portfolio.sqlite3`，无须点击保存。点击“返回训练列表”保留待成交订单；关闭并重新打开本地服务后，从同一用户的记录继续。

推进、下单、撤单和结束处理期间按钮锁定。网络中断或保存暂不可用、结果不确定时，页面保留**原请求**并显示“重试原操作”，禁止创建新操作。刷新同一浏览器标签页后仍可重试。服务恢复后重试原请求，后端负责去重；版本冲突会重新读取当前账户，再由用户重新决策。不要在等待时反复新建相同订单。

手动或自动播放到区间末日后，页面会自动结束、保存并直接展示总结；恢复已经到达末日的旧训练也会生成总结。也可以提前点击“结束并总结”，确认后撤销全部待成交订单并生成报告，持仓不会强制平仓。结束保存失败时保留原请求，可使用“重试原操作”恢复。

总结页包括总收益率、初始资金与最终资产、最大回撤、成交笔数、费用、盈利卖出占比、每日资产走势、各股已实现及浮动盈亏贡献，以及基于本次数据的复盘提示。各股贡献从账本汇总，包含分红等已入账收益，交易费用不会重复扣除。没有卖出成交时不计算胜率；该比例按卖出成交笔数统计，并非完整交易轮次胜率。无成交和沿用历史价格估值均有说明。

点击“查看 K 线与交易明细”展开原工作区，通过“结束后复盘范围”选择完整训练区间，可查看提前结束之后的行情；账户日期与估值仍保持结束日。点击“再开一局”回到新建表单，或返回列表随时重看总结。
