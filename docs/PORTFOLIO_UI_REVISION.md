# 组合界面交互调整与验收

日期：2026-10-27。按用户反馈对照原版 `frontend/index_enhanced.html` 和 `frontend/js/main_enhanced.js` 的悬停行情、MA5/10/20、右侧训练控制、手数输入及买卖按钮重新调整组合页面。

## 用户反馈与实现

| 反馈 | 现在的行为 |
| --- | --- |
| 悬停没有开高低收 | 鼠标指到 K 线或成交量时显示该日期的开盘、最高、最低、收盘、成交量、涨跌幅及当日 MA 值；两图十字光标联动，移开恢复最新有效日线 |
| 没有 5 / 10 日趋势线 | 默认 MA5、MA10、MA20，另可选 MA30、MA60；仅用已到达日期的有效收盘，数据不足时明确说明 |
| 所有股票一起看曲线 | 新增始终可见的“多股走势对比与组合收益”：全部个股涨跌幅线和含现金 / 费用的账户收益线，支持悬停及图例开关 |
| 自动模拟 | 右侧自动播放 / 暂停，0.5 / 1 / 2 / 5 秒每个公共交易日；串行等待保存完成再安排下一日，已有订单按原规则成交 |
| 买卖面板不直观 | 买入红色、卖出绿色，当前收盘价突出，执行日期和冻结预算 / 股数分行展示；说明提交、冻结、下一开盘和费用的关系 |
| 每次要自己填 100 的倍数 | 默认单位“手（1 手 = 100 股）”，输入 2 即发出 200 股；加减、1/5/10 手快捷按钮、卖出全部和零股模式均可操作 |

交易引擎仍按**股**接收数量，前端只在提交 / 试算边界将整数手数乘 100；没有改变原单股逻辑。自动播放只推进日期和处理已有订单，不会自动选股或代替用户下单。

均线与对比只读取组合 `/history` 截至公共日期的数据；不存在为了画线调用未结束报告或旧单股完整行情的路径。多股图的个股基准是训练内首个有效收盘，账户基准是初始现金；停牌沿用最近价格、上市前留空，图上显示具体口径。完整区间复盘仅在结束后作用于主 K 线。

## 浏览器实际验收

独立开发数据目录 `.runtime/step5`，本机预览 5055，所有操作为合成练习。未覆盖既有用户的单股记录。

- 创建三股多月练习，初始资金 100000 元。输入 **2 手**，提示 **200 股**；提交后下一开盘成交记录确为 200 股、开盘 12.00 元、费用 5.02 元。
- 自动播放连续推进到 2024-03-25，手动暂停后停止安排下一日；持仓仍为 200 股。MA5、MA10、MA20 已绘制且有数值。
- 选择卖出、输入默认 **1 手**，手动推进到 3 月 26 日，成交 100 股，价格 13.97、费用 5.71 元；剩余 100 股，现金 98986.27 元，总资产 100375.27 元。
- 刷新并恢复练习，日期及上述账目一致，自动播放默认暂停。
- 主图指向 **2024-02-20**，显示开盘 **13.33**、最高 **13.48**、最低 **13.10**、收盘 **13.25**、成交量 **142000 股**、涨跌 **-0.60%**；MA5 **13.34**、MA10 **13.21**、MA20 **12.65**，与最新日期区分。
- 切换到第二只股票，公共日期前后都是 **2024-03-26**。三股和账户同时在对比图显示；图例隐藏 / 显示、曲线悬停可用。对比图指向 2 月 15 日时，三股分别 +11.58%、+3.00%、+0.93%，账户 +0.27%。
- 另建 1 月 2 日至 4 日的停牌验收训练，买入乙 1 手后自动播放：到 1 月 3 日停牌拒单，日期停在 3 日，页面提示“已暂停：有订单未能成交”；现金和冻结全部恢复。手动推进至 4 日后，自动播放和下一日按钮禁用并提示区间末日。
- 390 像素窄屏按股票池、图表、交易面板和对比重排；已恢复正常预览宽度。

## 自动验证与截图

```powershell
node --test tests/js/portfolio_ui_math.test.cjs
node --check frontend/js/portfolio.js
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
.\.venv\Scripts\python.exe scripts/verify_baseline.py
.\.venv\Scripts\python.exe scripts/verify_portfolio_api.py
```

**125 项 Python 测试、5 项前端计算测试及两个 HTTP 验收脚本均通过。**前端计算测试独立核对均线首次有效值、停牌交易日口径、手 / 股转换、股价归一基准和未来异常值隔离。Python 新增多月样本创建、200 股真实入账、21 日推进、行情边界与显式演示开关测试。

原 7 日样本不足 MA10 / MA20，故另外提供 `synthetic-practice` 多月合成样本。它的价格和交易日历均为人工生成且明确标注，不能据此宣称真实历史区间已开放。真实准入规则维持原门槛。
