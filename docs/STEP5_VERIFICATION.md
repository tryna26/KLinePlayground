## 实际浏览器操作结果

所有业务动作均通过页面完成，没有用手动 API 调用代替页面买卖。

| 步骤 | 核对结果 |
| --- | --- |
| 1 月 2 日提交甲 200 股、乙 100 股买单 | 总资产 100000.00；可用现金 96854.97；冻结 3145.03；切换丙不改变账户或日期 |
| 推进到 1 月 3 日 | 甲按开盘 10.30 成交，费用 5.02；乙因已确认停牌被拒；现金 97934.98，总资产 100014.98 |
| 甲提交卖出 100 股，推进到 1 月 4 日 | 10.50 成交，佣金 5.00、过户 0.01、印花 0.53，费用合计 5.54；现金 98979.44，总资产 100039.44；甲剩余 100 股 |
| 乙买入 100 股，推进到 1 月 5 日 | 8.40 成交，费用 5.01；甲乙各 100 股；现金 98134.43，总资产 100064.43 |
| 丙买单保留待成交、返回列表、关闭重启服务 | 不开 `--portfolio-demo`，刷新页面继续训练，日期仍是 1 月 5 日，3 笔成交；待成交冻结 2271.02、可用 95863.41、总资产 100064.43 均一致 |
| 页面撤单 | 丙订单变为已撤单，冻结为零，可用现金恢复 98134.43 |
| 服务中断后提交甲 100 股 | 页面显示结果无法确认，保留原请求、禁用新操作；服务恢复后刷新标签页，“重试原操作”只生成一笔待成交订单，冻结 1193.01 |
| 输入过大股数 | 显示“可用资金不足，其他订单已占用资金”，提交按钮禁用，账户不变 |
| 结束并查看报告 | 释放最后一笔冻结；总资产 100064.43，收益 64.43（0.06%），3 笔成交，费用 15.57，已实现 11.95、未实现 52.48；报告与资产曲线一致 |
| 刷新后重新查看报告 | 日期、报告和账目一致；完整区间复盘可切换至 1 月 10 日的行情，账户估值仍明确为 1 月 5 日；返回截至结束日图表正常 |
| 390×844 窄屏 | 页面重排、股票池横向滚动、明细独立滚动；DOM 的页面可用宽度和内容宽度均为 375，没有整页横向溢出；已恢复默认视口 |

最终正常报告页浏览器控制台无 error / warn。中断验收时故意制造的连接失败属于预期场景。
