## 回归发现并修复的问题

1. 交易记录依赖 `../users`：统一使用明确的用户目录，外部工作目录下也不会写到别处。
2. 首次训练当前价格为零：初始化当前价格和 bar ID，首日即可查看可买数量并下单。
3. 结束训练只更新空的历史会话表：开始训练时先写入会话，保证复盘记录确实落库。
4. 同秒新建训练可能复用标识：训练 ID 加入微秒，避免快速创建覆盖。
