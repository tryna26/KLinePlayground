# 启动、数据更新与问题排查

## Windows 安装

需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime。安装包不需要管理员权限，默认安装到当前用户的 LocalAppData/Programs/KLinePlayground。程序、数据彼此独立，不覆盖已有其他安装。

没有窗口或启动失败时，先检查安装根目录 logs/desktop.log；WebView2 官方下载： https://developer.microsoft.com/microsoft-edge/webview2/ 。候选包未做代码签名；校验下载页提供的 SHA256 后按系统提示决定是否运行。

默认行情在安装根目录 data，用户记录在 users，桌面浏览器状态在 webview。可以使用 `KLinePlayground.exe --home <自选目录>` 改用独立目录，或分别使用 `--data-dir` 和 `--users-dir`。卸载保留这些运行资料，备份时在程序关闭后复制整个 data/users 目录；不要把数据写进 bin/_internal。

## 真实数据与范围

组合页面选择“真实日线 · 新浪”，点击“接入 / 更新真实数据”。下载和核验成功后，选择首批三只银行股，使用 2024-01-02 至 2024-06-12 范围内的交易日。先检查范围，再开始训练。

失败时查看中文提示和日志，确认网络可连接新浪、巨潮资讯。未核验区间不能靠复选框放行。更新失败保留已有核验材料；已保存训练使用固定观测，不依赖下次下载结果。若来源格式变更，请更新软件，不手改证据文件。

腾讯接口不可用时，组合训练可显式选择已接入的新浪源。单股仍沿用原数据源和规则。随机单股需要完整股票列表；网络失败时不会拿三只银行冒充全市场。

## 保存与重试

组合操作提交成功后自动保存。发生中断时使用页面“重试原操作”，不要反复新建订单；同一请求不会重复成交。待成交买单冻结资金、卖单冻结股数，切换股票不会解除占用。版本冲突时重新读取已保存状态。

用原本的同名本地用户继续训练。删除再重建同名用户不能继承已删除档案的组合记录。单股和组合使用不同存储，不能把单股旧缓存当作组合完整性证明。

## 开发和诊断

源码启动与测试见 DEVELOPMENT.md，构建见 ../BUILD_GUIDE.md。打包程序支持 `--serve-only --port 0 --ready-file <文件>` 输出本机诊断地址，仍只监听 127.0.0.1。关闭对应进程即可停止；此模式不应对公网开放。
