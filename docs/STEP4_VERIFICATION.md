## 交付

- 新增组合 API、独立 UUID、本地用户档案会话与逐训练归属检查。
- 独立 SQLite 保存配置、固定行情/日历/公司行为/费率、日期、账户、批次、订单、成交、流水、权益及资产曲线。

- 结束撤单、释放占用、生成按结束日估值的报告；仅结束后开放完整区间复盘行情。

## 真实 HTTP、硬重启与事务中断

`scripts/verify_portfolio_api.py` 在临时数据/用户目录启动 `127.0.0.1` 服务，使用合成行情完成：

1. 创建 10 万元、三股股票池的训练。
2. 下一开盘买入 600000 的 200 股，再部分卖出 100 股；现金 **98,979.44 元**，剩余成本 **1,032.51 元**，当时总资产 **100,039.44 元**。
3. 买入 000001 的 100 股，形成两股持仓；另保留 600036 的 100 股待成交买单。
4. 强制终止服务进程，然后在独立子进程的推进事务中、全部账户及请求结果写入之后、提交之前调用 `os._exit(73)`。
5. 重新启动原服务，此时关闭合成创建模式；逐字段比较恢复状态，原请求重试返回原结果。
6. 用中断请求的原标识重试推进，只生成一笔新成交；结束训练后读取完整报告，再次硬重启，报告及结束状态保持一致。

| 核对值 | 结果 |
| --- | --- |
| 保存日期 | 2024-01-05 |
| 共享现金 | 98,134.43 元 |
| 持仓 | 600000：100 股；000001：100 股 |
| 收盘总资产 | 100,064.43 元 |
| 已成交笔数 | 3 |
| 待成交订单 | 1，连同冻结额度完整恢复 |
| 中断子进程退出码 | 73，确认中断发生在提交前 |
| 恢复比较 | 完整 JSON 逐字段相等，账户版本不变 |
| 中断请求重试 | 日期仅推进至 2024-01-08，累计 4 笔成交 |
| 结束日总资产 | 100,129.41 元 |
| 报告再次重启 | 与重启前逐字段相等 |

结束前行情响应不含末日价格哨兵 `9999`，未来日期查询被拒绝；旧单股 `full_data` 对组合 UUID 返回 404。结束后只有当前档案的报告可以读取完整行情，其中含该哨兵。由此同时核对了恢复正确性和报告开放时机。
