# 组合训练使用说明

更新：2026-10-27。阶段五已提供可操作页面；本地练习，无实盘功能。

## 打开页面

在项目根目录启动：

```powershell
.\.venv\Scripts\python.exe run_dev.py --portfolio-demo --data-dir .runtime/portfolio-quotes --users-dir .runtime/portfolio-users
```

打开 <http://127.0.0.1:5050>，创建或选择本地用户，然后点击右上角“组合训练”。也可直接打开 <http://127.0.0.1:5050/portfolio.html>，使用顶部用户选择器。首次没有用户时，先返回单股票入口创建用户。

PowerShell 启动器也支持 `./start_dev.ps1 -PortfolioDemo -DataDir .runtime/portfolio-quotes -UsersDir .runtime/portfolio-users`。桌面启动可在 Python 命令末尾增加 `--desktop`；新 Windows 安装包留在阶段六。

页面默认选择“真实日线 · 新浪（已核验银行股）”，无需 `--portfolio-demo`。点击“接入 / 更新真实数据”，后端获取和核验资料后开放浦发银行（600000）、平安银行（000001）、招商银行（600036）的 **2024-01-02 至 2024-06-12**，共 105 个公共交易日。其他股票和日期仍需独立核验。接入方法、来源和验收见 [REAL_DATA_VERIFICATION.md](REAL_DATA_VERIFICATION.md)。

`--portfolio-demo` 额外开放明确标注的合成数据源。演示三个代码仅作标识，价格、停牌和上市退市状态均为人工样本。腾讯通道继续保留；所有真实通道都必须具备后端历史状态和公司行为完整性证明。已保存训练恢复不依赖联网或演示开关。

## 新建与继续

1. 保持“真实日线 · 新浪”，点击“接入 / 更新真实数据”。默认初始资金 100000 元，日期自动使用已核验的 `2024-01-02` 至 `2024-06-12`。
2. 搜索“浦发 / 平安 / 招商”或代码 `600000 / 000001 / 600036`，依次点击加入股票池；再次点击已选标签可移除。界面最多 20 只，首批真实准入限上述三只。
3. 点击“检查数据范围”。每只股票分别显示校验结果。变更股票、资金、数据源或日期后必须重新检查；不通过时不能开始。
4. 点击“开始组合训练”。所有股票共用一份现金和一个公共日期。
5. 继续已有训练时，在右侧记录中点击“继续训练”；已结束的记录显示“查看报告”。

搜索结果的“核验范围”是证据覆盖提示，不代表该区间中每一天都能成交。开始前还会检查整个请求区间的公共日历、行情、公司行为和费率。未核验的股票可加入待检查列表，但检查不会自动放行。真实区间准入格式见 [PORTFOLIO_API.md](PORTFOLIO_API.md)。

## 看图与下单

- 顶部大号日期是组合的公共日期，屏幕表示“截至该日收盘”。左侧列出股票收盘价、当天相对前一个有效收盘的涨跌、持有数量和数据状态；第一天没有前收盘时显示“—”。
- 点击左侧股票只切换日 K 和成交量，日期、现金、持仓和订单不变。训练中图表仅取截至公共日期的未复权日线。
- 右侧仿照原版使用红色“买入”和绿色“卖出”切换。数量默认单位为**手（1 手 = 100 股）**：输入 1 就是 100 股，输入 2 就是 200 股；可用加减和 1/5/10 手快捷按钮。卖出提供“卖出全部可申报持仓”，零股可勾选按股处理，仍由后端校验整笔零股规则。
- 右侧先从后端试算，显示预计执行日期、估算费用明细和冻结预算 / 股数。试算不落账；买入默认预留价格缓冲。正式下单后资金和可卖股数占用立即反映在所有股票的共享账户中。
- “当前可卖”不含当天买入以及已冻结的股票；“下一开盘可申报卖出”考虑下一交易日的 T+1。当天买入后可以提前提交下一日的卖单，但不能当天成交卖出。
- 点击“下一交易日”，公共日历、订单、所有股票和整个账户一起推进。订单按提交顺序使用下一日开盘价重新检查；资金不足不会产生负现金。
- 底部切换“全部持仓 / 订单与撤单 / 成交记录 / 资产曲线”。待成交订单可撤单，立即释放冻结额度。实际成交费用以成交记录为准，可能不同于估算。

### 悬停详情、均线和多股对比

将鼠标移到 K 线或成交量上，上方行情条显示光标所指日期的开盘、最高、最低、收盘、成交量、涨跌幅和均线值；离开后恢复最新有效日线。K 线与成交量十字光标联动。

默认显示 MA5、MA10、MA20，可勾选 MA30、MA60。只按截至当前日期的有效交易日收盘计算，历史不足 N 日时明确显示“不足 N 日”，不会用未来行情补足。

主图上方切换“单股 K 线 / 多股对比”，共用原图表区域；不会改变公共日期或交易对象。“多股对比”显示所有股票的价格涨跌幅与组合账户收益率，可通过图例隐藏 / 显示曲线。个股以训练内首个有效收盘为 0%，账户以初始资金为 0%；停牌沿用最近价格，上市前留空。该图始终截至公共日期；报告中的完整区间选项仅影响单股复盘图。左下角 TV 是 TradingView 图表库来源标识，图表下方也有说明。

### 自动播放

右侧“训练控制”提供自动播放 / 暂停和 0.5、1、2、5 秒 / 日速度。每次推进和保存完成后才等待下一轮，不会因慢请求重叠推进。它只自动推进日期并处理已有订单，不会自行选股或下新订单。

下单 / 调整数量、结束或返回列表会暂停播放；页面隐藏、订单被拒、请求冲突 / 中断、区间末日也会暂停。暂停时已经发出的本次推进可能仍会完成，之后不会再发起下一日。

想看足够长的均线，选择**“合成练习 · 多月均线与自动播放”**（需 `--portfolio-demo`），默认覆盖 2024-01-02 至 2024-06-28。价格和日历全部是人工样本，和真实历史数据分开。原 7 日演示样本仍保留，但不足以显示 MA10/20。

停牌、无有效成交、缺失行情、T+1 或成交拒绝均显示中文原因。停牌时可以使用带历史日期标记的价格估值，但不会使用该价格成交。日线无法重建盘口或排队，一字涨停买入、一字跌停卖出等按保守规则拒绝。

## 自动保存、重试与报告

每次成功操作自动保存到指定用户根目录的独立 `portfolio.sqlite3`，无须点击保存。点击“返回训练列表”保留待成交订单；关闭并重新打开本地服务后，从同一用户的记录继续。

推进、下单、撤单和结束处理期间按钮锁定。网络中断或保存暂不可用、结果不确定时，页面保留**原请求**并显示“重试原操作”，禁止创建新操作。刷新同一浏览器标签页后仍可重试。服务恢复后重试原请求，后端负责去重；版本冲突会重新读取当前账户，再由用户重新决策。不要在等待时反复新建相同订单。

点击“结束训练”，确认后撤销全部待成交订单并生成报告，持仓不会强制平仓。报告包括收益、费用、最大回撤、成交及资产曲线；结束后不能再交易。通过“结束后复盘”选择完整训练区间可查看结束日期之后的行情，页面明确标注复盘范围，账户日期与估值仍保持结束日。
