# 阶段六：Windows 候选包与发布验收

日期：2026-10-28。版本：4.0.0-rc.1。基于 fat7/KLinePlayground v3.2，保留上游历史和 MIT 许可。候选版只扩大到已经逐项核验的三只银行股和固定历史窗口，不表示任意 A 股历史都能回放。

## 环境与构建

使用隔离的标准 CPython 3.13.17 x64，安装 requirements-build.txt 的固定依赖；PyInstaller 6.22.3，Inno Setup 6.7.3。构建工具不修改系统 PATH 和原 Python 环境。原 3.12.14 开发运行时在冻结后的最小 SSLContext 测试中失败；标准 3.13.17 与 OpenSSL 3.5.9 的冻结测试和真实 HTTPS 下载均成功。并未关闭证书或主机名验证。

新版入口支持本机诊断、指定存储目录、轮转日志和自动分配端口；资源从冻结目录定位。安装到当前用户目录，无需管理员权限，保留原单股入口及组合页面。构建输入只允许前端、许可、说明和依赖资源，运行资料另行存放。

## 业务检查与证据

136 项 Python 测试、5 项前端计算测试通过。测试以独立预期值核对规则，明确标注合成样本；少量真实数据用于接入和打包后集成验收。修复了未来值测试把时间戳中相同数字误判为价格泄露的问题，改为匹配完整价格值，日期边界断言保留。

| 计划场景 | 验证范围 |
| --- | --- |

## 全新安装目录的十步验收

实际运行安装程序，在原本不存在的隔离目录安装后启动其中 bin/KLinePlayground.exe，没有复用源码服务或预拷贝行情。

1. 首次用户列表为空，创建本地测试用户，初始组合资金 100000 元。
2. 通过安装程序的 `/prepare-data` 下载日历、真实行情和核验材料，三只银行股 105 日预检通过。
3. 同日提交浦发 200 股、平安 100 股买单，可用现金为 97524.98 元。
4. 查询第三股日线，日期和账户逐字段不变；未来日期请求拒绝。
5. 01-03 开盘成交价分别为 6.59 和 9.19 元；现金 97752.98，总资产 100000.98。
6. 01-04 浦发部分卖出 100 股，现金 98411.64，总资产 99984.64，剩余两股各 100 股。
7. 再提交一笔浦发 100 股买单，保留为待成交，关闭进程。
8. 从同一安装目录重启，日期、账户、持仓批次、待成交、成交和资产历史的完整 JSON 一致。
9. 继续到 01-05，待成交只执行一次；结束报告与账本总资产 100009.63 元一致，现金 97746.63。
10. 原单股离线合成测试完成买入、当天卖出拒绝、下一日卖出和保存报告，最终资产 99989 元。

测试结果保存在本地隔离目录，不随源码或安装包上传。

最终安装包再次在全新目录通过同一十步验收。随后运行卸载程序，程序文件被移除，用户组合数据库仍存在且 SHA256 完全不变。便携 ZIP 的 1073 个归档文件逐项核对清单后，在另一个全新目录启动、下载真实数据并完成三股预检，全部通过。

## 实际界面

安装后的 WebView2 窗口已启动，可访问性树确认完整页面、真实用户选择、数据源和报告入口。Windows 原生窗口截图接口出现 `FrameArrived timed out`，因此截图与点击验收使用同一个已安装程序提供的本机页面；没有将浏览器截图称为原生窗口截图。

浏览器完成三股创建、两股买入、部分卖出、自动播放、暂停和上方视图切换；回放至 2024-05-30，均线和对比收益正常，控制台无错误。证据：screenshots/phase6-installed-kline.png、screenshots/phase6-installed-comparison.png。

## 分发与限制

发布文件包括 Windows x64 安装包、便携 ZIP、逐文件 bundle-manifest.json、SHA256SUMS.txt。完整第三方许可放在 LICENSES；源码保留 LICENSE、THIRD_PARTY_NOTICES.md、上游署名和来源链接。真实行情缓存、用户数据、API 凭据、虚拟环境、日志和个人路径不纳入新提交。整个待推送历史和新增源码分别进行密钥与敏感路径检查。

发布审查：最新源码清单 126 个文件，无运行数据库、开发缓存、凭据文件或个人绝对路径；Gitleaks 8.30.1 对所有分支/合并历史及单独导出的待发布源码均未发现密钥。由 Git 索引导出的干净源码目录使用新建的固定依赖环境运行，136 项测试及原单股 HTTP 验收再次通过。

首批真实数据仍为浦发、平安、招商银行的 2024-01-02 至 2024-06-12。安装包未做代码签名，需要 Windows 10/11 x64 和独立的 Microsoft Edge WebView2 Runtime。没有打包旧的独立 AI 测试器；该辅助工具在上游缺少前端资源，不属于本次组合训练安装入口。
