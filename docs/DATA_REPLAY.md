# 组合训练：数据接口与回放边界（阶段二）

更新：2026-10-27。数据结构版本：1。

阶段二交付后端数据接口、公共交易日历、历史状态和公司行为准入检查，以及固定验收数据集。阶段三已新增 [组合账户和账本引擎](PORTFOLIO_ENGINE.md)，阶段四已新增 [HTTP 保存恢复和报告接口](PORTFOLIO_API.md)；组合页面属于阶段五。本模块没有注册到原单股 `active_trainings`，不能通过原单股接口访问。

## 模块与调用方向

| 模块 | 职责 |
| --- | --- |
| `backend/replay_models.py` | 原始日线、数据状态、历史状态证明、公司行为证明和严格校验 |
| `backend/tencent_source.py` | 共用腾讯请求；组合使用无清洗丢行的原始日线入口 |
| `backend/replay_data.py` | 行情源协议、腾讯适配器、隔离缓存、按日补取和状态判定 |
| `backend/replay_calendar.py` | 独立公共交易日历、覆盖检查和下一交易日 |
| `backend/replay_storage.py` | 带版本和 SHA-256 校验的原子文件写入 |
| `backend/portfolio_replay.py` | 公共日期和向图表、指标、账户提供的可见数据门面 |

行情下载与内部缓存允许持有训练区间全量数据。图表、指标、账户和后续 HTTP 路由只能拿到 `PortfolioReplay` 的输出，不能拿到 `QuoteRepository`、`QuoteBundle` 或下载函数。Python 私有属性不是安全沙箱；HTTP 层必须保持上述依赖方向，禁止把内部对象直接序列化。

## 统一行情接口

`DailyQuoteSource` 必须提供 `name`、`version`、`synthetic` 和 `fetch(code, start, end)`。请求范围是包含两端的自然日日期；返回行必须包含 `date/open/high/low/close/volume`。股票代码严格限定沪深主板 A 股六位代码，不从任意输入中提取数字，不把指数或基金当成股票。

价格统一为人民币元、未复权价格，成交量统一为股。`Decimal` 保存价格与成交量，序列化为十进制字符串，图表需要浮点数时在显示适配层转换。腾讯主板日线的原始成交量按每手 100 股转换；单股旧缓存口径保持原有含义，组合模块不会自动导入它。

每个 `QuoteState.to_dict()` 含以下字段：

| 字段 | 含义 |
| --- | --- |
| `stock/date` | 股票与本次查询的公共日期 |
| `status/reason` | 数据状态及普通中文说明 |
| `bar` | 当日有效原始日线；无可用行情时为 null |
| `source/updated_at/data_version` | 行情来源、带时区的获取时间、行情内容版本；没有行情来源时可为 null |
| `status_source/status_version` | 历史状态核验来源和版本，独立于价格来源 |
| `price_basis/volume_unit/schema_version` | 固定为 `unadjusted` / `share` / 1 |
| `execution_data_ready` | 仅表示存在可供订单校验的有效成交行情，不表示订单一定成交 |

`snapshot()` 还会为估值附上 `valuation.price/price_date/stale`。停牌可用截至当前日期最后一个有效收盘价估值；成交接口不得使用 `valuation` 替代当日 `bar`。训练开始前没有可见价格时不填估值。

## 数据状态与补取

| 状态 | 判定与处理 |
| --- | --- |
| `trading` | 核验过的普通交易日，有有效价格和正成交量；后续仍需检查涨跌停、T+1 等 |
| `suspended` | 该日明确存在于核验过的停牌历史；不合成 K 线，不允许成交 |
| `not_listed` | 早于核实的上市日 |
| `delisted` | 达到核实的退市生效日，该日即已非上市状态 |
| `download_failed` | 下载异常，禁止使用旧价格代替成交 |
| `cache_missing` | 未缓存、缓存损坏/过期且离线，或缓存写入失败 |
| `unknown` | 生命周期未核实，或补取成功仍没有该日行情；禁止当成停牌 |
| `invalid` | 非法价格、成交量、日期、字段或同日冲突记录 |
| `no_trades` | 成交量为零；可展示日线，禁止成交 |
| `market_closed` | 公共日历确认休市 |
| `unsupported` | 特殊历史状态，或误将合成数据用于真实训练 |

`QuoteRepository.prime()` 先准备指定范围，`quote()` 发现缺失时尝试一次针对该日的补取并重新校验。已确认未上市、退市或停牌的日期不重复下载。原因不明、下载失败或数据无效会阻止训练进入该日，公共日期保留原值；其他股票不会先行推进。

校验不会静默删除坏行：日期必须合法且落在请求范围内；价格必须为有限正数且符合开高低收关系；股数必须为有限非负整数。输出按日期升序且唯一。数值相同的重复记录折叠，冲突重复使整批失败。组合创建时还检查行情是否错误出现在公共休市日。

## 公共交易日历

使用新浪独立交易日历，沿用已安装 AKShare 的解码器和 1992-05-04 补正，HTTP 请求单独设定连接/读取超时，在本次请求会话内绕过环境代理，不修改系统代理。下载失败报错，不回退到工作日推算、指数日线或多只股票有行情日期的交集。

`ReplayCalendar` 记录实际返回的日期、来源、内容版本和获取时间。覆盖边界以实际返回的首末交易日为准，不推断末日之后的休市日。本次在线核验返回 1990-12-19 至 2026-12-31；这一结果不是对未来源站范围的保证。

日历默认使用已保存的版本，调用 `load_public_calendar(data_dir, refresh=True)` 显式刷新。超出覆盖范围必须先刷新或缩小区间；首尾日期必须为公共交易日。切换股票没有修改日期的权限，推进使用同一个公共日期序列。

## 历史状态与公司行为的准入条件

`SecurityHistory` 需要核实上市日、退市日、停牌日期，以及 ST、退市整理等特殊状态区间。不能使用当前股票简称判断历史状态。`Evidence` 必须含覆盖起止日、来源、版本、核验依据和带时区的核验时间。

`ActionHistory` 的证明表示指定股票、指定区间内**所有可能影响现金或股数的公司行为已经完整核验**，并非“接口返回了几条分红”。生产数据只能由受信任的后端导入流程创建 `scope="reviewed"` 的证明，不能接受浏览器传入的“已核实”布尔值。仅覆盖部分事件或只查到一个源的空表时，不能建立完整性证明。

已核实的数据源条件如下：

| 来源 | 能确认的能力 | 本阶段如何使用 |
| --- | --- | --- |
| 腾讯原始/复权日线 | 价格序列及显示复权信息 | 原始价格用于组合行情；复权因子不能充当公司行为账本 |
| 原项目 `get_dividend_data()` | 只读取本地 `ex_dividend/<code>.csv`，没有下载与覆盖证明 | 不能据其文件不存在或表为空判断“历史无事件” |
| AKShare 新浪分红配股接口 | 分红和配股记录分开查询，有事件日期等字段 | 可作为后续核验输入；接口说明未承诺逐股全历史完整性，不自动准入 |
| AKShare 巨潮历史分红接口 | 有每 10 股比例、登记、除权、派息及股份到账等信息 | 可补充生效时点核验；仍需逐事件核对，不覆盖所有公司行为类型的完整性证明 |

默认数据回放仍不启用公司行为核算；阶段三引擎配合 `accounting=True` 可支持有明确登记日、同日生效与入账、税后每股金额/送转比例、可卖日和除权参考价的现金分红、送股与转增。具体结构、账本及限制见 [组合引擎说明](PORTFOLIO_ENGINE.md)。配股、拆并股、未知类型、分离的生效/入账窗口及信息不完整的事件仍不能跨越。不能从登记日之后开始却忽略已有权益的后续生效日。

允许的真实区间需要历史状态、公司行为完整性、原始行情及日历全部有效；有事件时还须通过引擎支持条件。当前仓库**没有发布任何已获完整性证明的真实股票区间**，因此不会默认开放真实组合训练。在线验证只证明数据接入可用，不能替代完整性核验。

合成验收样本的证明为 `scope="synthetic"`，只有显式 `synthetic=True` 才可使用。证券代码只作标识，其价格、停牌及上市/退市时间均不是实际证券历史。不能通过修改测试模式参数把合成证明用于真实训练。

阶段三已用合成事件验证相应现金、股数和成本账本处理。配股等复杂事件继续阻止。这个门槛保留在创建与回放数据入口中，不依赖前端按钮状态。

## 缓存、刷新和可复现性

缓存位于调用方指定行情目录的 `portfolio_replay/`，不复用原单股 `kline_raw/` 或 `factor/` 文件。

- 行情文件的键包含来源、适配器版本、股票和请求起止日期。元信息同时记录实际有行情的覆盖日期、更新时间、股数单位、价格口径、合成标识和内容 SHA-256。
- 默认有效期 24 小时；过期时联网补取，离线时拒绝。明确选择固定历史缓存时可用 `max_age=None`，仍检查结构版本、来源、口径、内容校验值及全部行情行。
- `prime(..., refresh=True)` 显式刷新；失败不覆盖原文件，但当前仓库对象将该区间标记为不可成交。成功的一日修复仅修复该日，不会让其他下载失败日期恢复可用。
- 文件先写同目录临时文件并刷盘，再原子替换。真实缓存不进入 Git；损坏或版本不匹配不静默兼容。
- 训练创建时固定每日观察值；此后的外部刷新不会改变这次训练的历史价格。后续保存恢复应保存这些数据版本和训练状态，见阶段四。

## 未来数据隔离

`PortfolioReplay.current_date` 由内部公共日期游标控制，外部不能赋值。`switch_stock()` 只改变当前查看股票。

`history()/chart_data()/indicator_data()` 只返回截至当前日期的未复权日线；`account_data()/snapshot()` 只含当前状态和可见估值。即使指定 `through` 也不能读取未来日期。输出是新生成的数据字典，修改它不会改变训练快照。

`full_data()` 明确拒绝读取完整未来行情，`history(full=True)` 也没有入口。阶段四仅在用户归属及 `ended` 状态校验通过后，经专用报告接口提供完整区间行情；普通历史接口始终保留截至组合日期的边界。

已审查旧处理器：原 `forward` 模式使用 `full_data.iloc[-1]` 的复权因子，旧单股 `full_data` 接口可直接输出完整区间。组合模块因此不复用这两个入口，暂时仅支持未复权图表；调整图表显示不能改变原始成交价或账户估值。阶段四新增路由必须持有这个数据门面，不能把组合对象塞进旧单股训练容器。
