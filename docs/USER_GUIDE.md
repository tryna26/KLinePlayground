# 第一次使用组合训练

## 安装和开始

从本项目 GitHub Releases 下载 Windows x64 安装包，核对同页 SHA256SUMS.txt。运行安装程序后打开 KLinePlayground。便携 ZIP 解压后运行 bin/KLinePlayground.exe；两种方式均需要 Microsoft Edge WebView2 Runtime。

当前源码：在首页创建本地用户，点击“新建训练”，在“训练类型”选择“组合训练”。指定模式可输入多只股票代码（逗号或空格分隔），选择起止日期、数据源和初始资金，直接点击“开始组合训练”。系统自动加载行情，周末和节假日起止会对齐区间内交易日。可选 1–20 只股票，不限三只银行股，也无需单独检查核验区间；所选数据源须实际覆盖请求日期，结束日期须早于今天。

选择“盲盒模式”后，可设置板块、抽取股票数量、日期范围和训练交易日数。系统随机抽取符合共同数据范围的股票与起点。如果本地离线行情不足，可减少数量、缩短时长或扩大日期范围。原 v4.0.0-rc.1 发布包仍使用旧版三股流程，需要重新构建才包含本次修改。

## 先认识公共日期

大号日期表示你已经看到这一天的收盘行情。所有股票和账户共用这一天；点股票只换图，日期不会变。你不知道下一天的开盘价。

在“单股 K 线”中，鼠标指向某根 K 线可看该日开高低收、成交量与涨跌幅。均线 MA5/10/20 等使用截至当前日期的有效收盘价，天数不足时显示不足。切换“多股对比”可同时看所有股票与组合收益，图例可开关曲线。左下角 TV 是图表库来源标识。

## 买入一手，再推进一天

选择股票，点红色“买入”，数量填 1，即一手 100 股；填 2 即 200 股。右侧显示参考收盘价、手续费估算和本单冻结预算。买单预算包含价格缓冲，提交后先冻结，不代表已经成交。

点“下一交易日”，所有股票同时前进一天，已有订单按下一天的实际开盘价和模拟费率检查。成交后多余预算退回；开盘跳空、资金不足、无有效成交或一字行情等会拒绝订单，并写明原因。不要把今天的收盘价当成明天一定能成交的价格。

页面的估算预算会高于按参考收盘价计算的成本，实际成交以次日开盘和费用明细为准。

## 卖出、撤单和费用

绿色“卖出”只能卖持有的股数。“当前可卖”排除当天买入和已冻结的股数；“下一开盘可申报”考虑下一交易日的 T+1。当天买入后可以提交下一日的卖单，不能当天成交卖出。

数量仍按手输入；卖出全部按钮自动计算，零股需选择按股处理并通过规则校验。部分卖出后剩余持仓继续保留成本。费用包括佣金、过户费、卖出印花税，实际成交明细以底部“成交记录”为准。默认最低佣金 5 元，小额交易也会产生这笔费用。

不想执行的待成交订单，在“订单与撤单”中取消；被冻结的现金或股数随即释放。

## 自动播放和保存

“自动播放”按所选速度推进公共交易日并处理已有订单，不会自动替你选股或下新订单。暂停时已发出的本次推进可能完成，之后停止。调整订单、返回列表、隐藏页面或遇到拒单等情况会暂停。

操作成功后自动保存。顶部固定的“返回训练列表”保存当前进度并退出，“返回首页”回到主入口。关闭程序后使用同一个本地用户，在“新建训练 → 组合训练 → 继续已有组合训练”中点“继续训练”。网络中断出现“重试原操作”时用该按钮确认结果，避免新建重复请求。

“结束训练”取消待成交订单并生成报告，持仓按当前收盘估值，不强制卖出。结束后不能继续交易，但可复盘完整区间。底部资产曲线反映现金、费用和持仓整体收益；个股涨跌幅不等于账户收益。

## 支持范围

这是本机历史日线模拟，不能还原真实盘口、滑点和排队。自由组合使用未复权价格、固定模拟费率，不计分红送转，不能作为精确历史收益回测。佣金万三、最低 5 元，卖出印花税万五、过户费十万分之一；缺失行情不成交。原有已核验训练保留其保存时的历史费率及规则，恢复时继续使用原固定快照。

遇到启动、下载或恢复问题，见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。源码开发与构建见 [DEVELOPMENT.md](DEVELOPMENT.md) 和 [BUILD_GUIDE.md](../BUILD_GUIDE.md)。
